# Themes for Donkey Kong

A theme changes how the game looks and sounds. The game itself, its rules in `model.toml`, stays the same.

This folder holds no theme. `kit/` is the theme kit: the list of pictures and sounds a theme has to supply, with their sizes and places. A theme maker starts from it.

Each theme is its own package in its own repo, so it can carry its own pictures and licence and be published without a change here.

| Theme | What it is | Where it lives |
|---|---|---|
| Original | The game's own art and sound, lifted from your ROM when you play. Never stored in a repo. | Your ROM |
| Turnips | A clay look, with new pictures that hold nothing from the ROM. | https://github.com/lex00/turnips (package `lex00/turnips`) |

On the page, pick one under Settings, Theme.

When a new theme for this game is published, add a row here.
